# Travel Guide Planner 模板与话术参考

本文件配套 `SKILL.md` 使用，包含第一阶段的前置问询模板、第二阶段的冲突预警模式，以及第三阶段的标准路书输出骨架。

---

## 一、前置问询模板（按缺失项精简裁剪）

调用本模板时，先剔除用户已经明确说明的条件，仅保留待确认项，控制在一次回复 5 条左右：

```markdown
为了把每日路线、交通衔接和费用预算算准，在开始排行程前先向你确认几个关键信息（已提到的部分我已记录，只需补充下面这几项）：

1. **精确停留时间**：几月几日出发与返程？去程大约几点落地/到站，返程大约几点离开？
2. **同行人与身份优惠**：共几人同行，有没有老人、小孩或对行程强度/饮食有特殊顾忌（如不吃辣、易晕车、高反）？是否有学生证、老人证等可享受门票优惠的证件？
3. **预算与花钱偏好**：人均总预算大概多少（是否包含往返机票或高铁）？更愿意把预算倾斜给好一点的住宿地段、特色美食，还是尽量压缩吃住多留给游玩体验？
4. **游玩节奏与当地出行**：偏向多打卡地标的紧凑路线、博物馆人文深度游、纯逛吃，还是睡到自然醒的慢节奏？在当地倾向“地铁+步行/打车”，还是租车自驾或包车？
5. **住宿与避坑底线**：对酒店位置或房型有什么底线要求（比如近地铁、带电梯、双床）？有没有明确不想去的项目或以前踩过雷的地方？
```

## 二、约束冲突确认话术模式

当发现时间、体能或预算存在冲突时，先用简洁说明让用户拍板：

```markdown
根据你目前的条件，排程前先提醒一个需要取舍的地方：
- **冲突点**：[例如：你只有 1.5 天有效游玩时间，但同时想逛市区三大场馆和车程单程 2 小时的远郊景区，硬排会导致全程赶路且无法顾及老人体能。]
- **可选方案 A（保深度与轻松）**：[舍去远郊景区，聚焦市区顺路片区，每天只安排 1-2 个核心点。]
- **可选方案 B（保远郊核心景）**：[放弃市区博物馆，把完整一天留给远郊景区并考虑包车往返。]

你更倾向方案 A 还是方案 B？确认后我立即为你输出完整路书。
```

## 三、标准定制路书输出骨架

### 1. 出行画像与核心前提

> - **目的地与天数**：[城市名称] / [X天X晚]（[日期范围与淡旺季提示]）
> - **有效时间窗**：去程 [X月X日 XX:XX 抵达] 至 返程 [X月X日 XX:XX 离开]
> - **同行与节奏**：[人数与人群特征] / [游玩风格与每日出行强度]

### 4. 预约抢票与交通避坑汇总

- **硬性预约清单**：按提前放票天数倒序排列必须提前预约的场馆、官方公众号/小程序名称及每周闭馆日。
- **门到门交通提示**：大交通接驳首末班时间、推荐本地交通卡或乘车码、机场/车站反黑车及景区低价野团提醒。
- **饮食与购物边界**：列出当地高发游客溢价雷区，以及推荐采购正宗特产的本地大型超市或菜市场方向。

### 5. 行前核对与应急清单

- **证件与备份**：身份证、门票优惠证件、驾照（自驾用）、订单与预约码本地相册离线截图。
- **穿衣与装备**：对应季节温差穿搭、防雨防晒用品、磨合过的舒适运动鞋、充电宝及个人常用药。
- **应急联络**：住宿酒店前台电话、当地旅游咨询投诉热线、三甲医院方向或境外领事保护热线。

## 四、手账画册风 4 页通用结构模板（少字、去 AI 腔、PDF/Word 专用）

当用户要求“少字简洁、图片主导、手账特色、直出 PDF/Word”时，禁用呆板公文套话与大段文字表，改用 **4 页紧凑手账骨架**（字体字阶、防空白 `gap` 控制与双渠道配图规范见 [visual-pdf-blueprint.md](./visual-pdf-blueprint.md)）：

```markdown
[Page 1 · 拍立得封面、车票票根、穿搭便签与记账预算]
- 左栏：代表性实拍/真实感 Hero 大图（贴胶带拍立得相框 + 简洁标题与行程标签）
- 右栏：起止城市票根（不预设出发地） + 黄色天气穿搭便利贴（写明晴雨日程分配）
- 中栏：3 张贴纸小便签（官方抢票通道 / 证件刷卡硬要求 / 抵离时刻基准假设）
- 下栏：5 项蜡笔预算条卡片 + 优惠门票/免费地标圆戳印章卡
- 底栏：交通枢纽对比与住宿锚点选址理由（消除底边大面积空白）

[Page 2 · 拍立得拼贴相册与“省力不爬山”原则条]
- 上区：4 大核心地标 2×2 拍立得卡（控高 56–58mm 防拥挤；仅写价签 + 1–2 句省力玩法短句）
- 中区：3 处住宿中心与顺路街区 1×3 邮票卡（控高 41–43mm；含本地低价观海/环城公交线）
- 底栏：全程省腿/少折腾原则 3–4 条口诀

[Page 3 · 增高版手绘路线图与双栏手账时间轴]
- 顶部：内嵌手绘风 SVG 空间路线图（带海岸/水系曲线、简笔涂鸦、描边防遮挡文字与图例 gap）
- 中部：Day 1 / Day 2 微倾记事本页（竖直虚线串联时段 + 耗时单价高亮标 + 具体行动口诀）
- 下部：大风/降雨与夜归备选便利贴 + 本地乘车码及经典公交线路底栏

[Page 4 · 当地美食价格小本本、行前勾选与伴手礼底栏]
- 顶部：2 张美食实景/干净合成大图拍立得（严格匹配忌口如 0 辣画面 + 核心品类价格区间）
- 中部：6 格核实地址版美食手账卡（真实店名/路名 + 高亮实价 + 必点菜 + 口味/防排队口诀）
- 下部：[✓] 四格行前核对清单 + 右下圆戳邮章 + 底部点单暗号与伴手礼真实区间
```

# Travel Visual PDF Blueprint（通用手账画册式 PDF 排版与质检蓝本）

本蓝本用于将任意城市的旅游攻略输出为**真实美观、手账质感、少字清晰、图片主导**的 4 页 A4 成品 PDF，消除“AI 报表风”、解决小字发虚与页间留白失衡问题。

---

## 一、核心视觉、篇幅与字阶规范（通用任意目的地）

| 维度 | 推荐标准 | 核心原因 |
| :--- | :--- | :--- |
| **页面规格** | **4 页全出血 A4 竖版**（`210 × 296.8mm`，内留白 `9mm × 11mm`） | 浅米色点阵手账纸满铺，每页专注一个核心阅读任务 |
| **间距布局铁律** | `display: flex; flex-direction: column; justify-content: flex-start; gap: 9.5px;` | **严禁使用 `space-between`**，避免内容少的一页区块间被拉出巨大空白断层 |
| **字体清晰组合** | **标题**：华文新魏 `STXINWEI.TTF` + 华文中宋 `STZHONGS.TTF`<br>**正文/数字**：等线与粗体 `Deng.ttf` / `Dengb.ttf`（`9.4pt`）<br>**标签/徽章**：幼圆 `SIMYOU.TTF`（`8.2–8.8pt`） | 兼具手作温度与移动端/打印端高锐度；避开细楷体写小字导致的发虚模糊；本地引用仅用 ASCII 文件名 |
| **篇幅与视觉占比** | 图表/照片占版面 **65% 以上**，每页上下均匀铺满（底部留 `10–14mm` 自然边），无多余空白与孤立尾页 | 手机竖屏或打印双面翻阅均轻松顺滑 |

---

## 二、4 页通用手账页面结构骨架（无既定城市）

1. **Page 1 · 拍立得封面、票根、气候穿搭与记账预算**
   - **左区 Hero 拍立得大图**（图高 `96–100mm`）：城市代表性实景横图，微倾 `-0.75°`，顶部贴两条半透明和纸胶带，底部白边手写风格大标 + 画像标签。
   - **右区高铁/机票票根 + 黄色天气便利贴**：票根卡展示起止城市与核心约束标签；便利贴写明未来几日逐日气温风力、穿搭要点及晴雨排程逻辑。
   - **中区 3 张胶带小便签**：拆解实名抢票通道、证件刷卡硬要求与抵离车次基准假设。
   - **下区手账记账卡（蜡笔进度条）+ 优惠票印章卡**（含圆形邮戳印章）+ **底部通栏**：交代枢纽站对比与住宿锚点选址理由，消除页底大块空白。

2. **Page 2 · 拍立得拼贴相册与“省力不爬山”原则条**
   - **上区 `2×2` 核心地标拍立得卡**：写真图高 **`56–58mm`**（严格控高防第二页过度拥挤！），配左下角悬浮路线胶囊标签、华文中宋景点名 + 荧光黄价签 + 1–2 句省力看点短句。
   - **中区 `1×3` 住宿中心与街区邮票卡**：写真图高 **`41–43mm`**，覆盖住宿商圈锚点、本地早/夜市及经典低成本公交观光线。
   - **底部手账通栏**：总结本次行程的省力原则或动线避坑口诀，上下呼吸感舒朗均匀。

3. **Page 3 · 增高清晰手绘路线图、双栏时间轴与 Plan B**
   - **上区手绘风 SVG 空间拓扑图**（图高 **`170–180px`**）：
     - 顶部图例严格用 `display: flex; gap: 10px;` 且文字简短防碰撞；
     - 用曲线岸线、水波纹、交通工具/地标简笔涂鸦、虚线接驳线与 **`paint-order: stroke`** 描边光晕文字，一眼理顺“抵达枢纽 — 住宿核心 — 分日环线 — 返程”。
   - **中区左右双栏手账日记页**：分日虚线纸张微倾 `±0.25°`，用竖直虚线时间轴串联每站，突出时段、单段耗时/费用荧光标与人话点单/乘车提示。
   - **下区两格 Plan B 便利贴 + 底部通栏**：雨天/大风替补馆方案、夜间交通换线兜底及当地电子乘车码口诀。

4. **Page 4 · 当地特色美食价格图鉴、行前勾选与伴手礼底栏**
   - **上区双幅美食大图拍立得**（图高 **`65–68mm`**）：左幅呈现地道正餐与粉面代表，右幅呈现市集古早小吃与甜品饮品，下方直接标出核心品类实价与口味说明。
   - **中区 `2×3` 实查门店点菜手账卡**：每格写清**真实店名/门牌号、单品/人均实价、必点搭配、辣度或忌口对策**，标题严格控制单行不折断。
   - **下区行前 `[✓]` 四格勾选单 + 右下角邮戳圆章**（右侧留足 `padding-right` 防文字与圆章重叠）+ **底部手账通栏**：点单暗号与真实伴手礼带货区间。

## 三、双渠道图片采集与质检操作规程

1. **第一步（优先网搜实拍）**：先检索目的地代表风貌与美食的真实无水印高清实拍图；使用 `read_file` 检查无水印、不杂乱、无错季违和感且长宽比适配后再保存入版。
2. **第二步（按需真实感生图）**：仅在搜不到合适实拍、图片杂乱带水印、或菜品拼盘需要统一洁净构图时启用生图；生图提示词严禁虚构不存在的建筑与景观，必须严格匹配用户口味禁忌（如不吃辣餐图不可见辣椒红油），生成后同样经 `read_file` 核验才可使用。

## 四、通用 CSS 骨架与自动化导出验版

- **通用 HTML 启动样板**：直接参考或复制 [lookbook-template.html](../examples/lookbook-template.html)（已内置上述 `gap` 等距排版、拍立得/胶带/票根/印章样式及跨平台字体回退）。
- **推荐导出脚本**：运行 [export_pdf.py](../scripts/export_pdf.py)（使用隔离 `--user-data-dir` 防止 Edge 进程抢占静默失败，并通过临时文件中转检测目标 PDF 占用锁定）：
  ```bash
  python scripts/export_pdf.py --html guide.html --out output.pdf --preview-dir previews --dpi 160
  ```
- **交付前必检**：逐张调用 `read_file` 检查导出的 `pdf_page_1.png ... pdf_page_N.png`，确认四页均字体清晰饱满、第 2 页不拥挤、其余页区块间无过大空隙、价格无折行截断、印章不压字，最后同步创建/更新右侧 `UserFacing: true` `.md` 预览 Artifact 并双附链接。

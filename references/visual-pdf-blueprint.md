# Travel Visual PDF Blueprint（少字图鉴版 PDF 排版与质检蓝本）

本蓝本用于将旅游攻略直接输出为**高颜值、少字数、图片主导**的成品 PDF（亦可用于 HTML 预排版后转制展示册），解决纯文字攻略冗长难读的问题。

---

## 一、核心视觉与篇幅指标（以 2–4 天短途为例）

| 指标 | 目标标准 | 说明 |
| :--- | :--- | :--- |
| **总页数** | **4 页**（短途）/ **4–6 页**（中长途） | 一页聚焦一个主题模块，严禁尾页仅溢出 1–3 行 |
| **非空白字数** | **1,800 – 2,600 字** | 相比传统长文压缩 45%–55%，用价格徽章和短句标签替代长段落 |
| **图文面积占比** | **视觉与图表占 65% 以上** | 依赖大图、比例条、SVG 空间拓扑图与色块时间轴传递信息 |
| **美食要素覆盖** | **正餐 + 早餐/粉面 + 饮品小吃 + 夜市** | 必须配美食实拍大图、人均/单品价格与微辣/排队提醒 |

---

## 二、4 页标准画册式页面骨架（Page-by-Page Layout）

1. **Page 1 · 大图封面、气候穿搭与可视化预算**
   - **Hero 大图封面**（高约 `105–115mm`）：代表性城市秋/季景全幅横图 + 底部深色渐变遮罩（`.hero-scrim`）放置城市主题标签、主标（`24–26pt`）及核心画像副标（预算/住宿锚点/交通偏好/饮食底线）。
   - **4 格核心指标栏（KPI Strip）**：`气候温度` | `预算实测` | `身份折扣` | `主出行网`。
   - **3 条出发前硬提示卡**：官方必约通道、高热门场馆兜底备选、本次排程依据的抵离时刻假设。
   - **可视化分项预算条（双栏下半区）**：左侧为各费用项的**彩色水平比例条 + 金额区间**（大交通、住宿、餐饮美食、门票与区间车、市内交通与机动备用金，总计一目了然）；右侧为逐日气候徽章、三层穿衣口诀及优惠证件单点票价速算卡。

2. **Page 2 · 核心地标与顺路街区视觉图鉴**
   - **上区：四大核心地标 `2×2` 大图卡**：每张卡固定图片比例（`object-fit: cover`）+ 角落价格/时长浮标，文字严格限定为：**标题 + 价格单行徽章 + 1 句高密核心提示**（地铁口、最佳光线、零爬山/省力动线、预约渠道）。
   - **下区：三大顺路街区/住宿锚点 `1×3` 卡片**：展示住宿片区枢纽（说明地铁直达性与淡季价位）及两处顺路历史/步行街区。

3. **Page 3 · 无折返空间路线图与两日极简时间轴**
   - **上区：内嵌 SVG 地铁/交通空间拓扑图**：
     - 顶部图例（`.svg-leg`）使用 `display: flex; gap: 10px–14px;` 与简短站名，避免文字贴碰相邻线色标；
     - 用线路色条、空/实心站点圆圈、跨江/方位底色与单向动线箭头直观标注“机场/高铁站 — 住宿中心 — 景区片区 — 夜市/返程”的空间关系。
   - **中区：左右双栏分日时间轴卡**：按时段拆分色块条目，每条仅保留 `起止时间` + `核心主题` + 3 枚微标签（`交通耗时`、`单段费用区间`、`实操要点`）。
   - **底区：两格 Plan B 兜底栏**：左侧列大风/雨天室内替换动线，右侧列热门场馆约满或热门餐厅排长队时的平替方案。

4. **Page 4 · 当地特色美食价格图鉴与行前 4 项速查**
   - **上区：双幅美食大图对比横幅**：左幅展示特色粉面与地道家常正餐，右幅展示街头爆款小吃、本地茶饮与夜市摊位，图片下方用单行写明品类均价与口味策略（如“原汤不辣自助加剁椒”、“微辣友好菜品”）。
   - **中区：6 格本地美食价格矩阵（`2×3` 卡片）**：每格包含 `店名/品类` + **右上角高亮价格区间（`XX–XX 元`）** + `2–3 道招牌菜名` + `1 句避坑/取号/辣度提示`。
   - **下区：出发前 4 项速查 + 极简尾注**：`住宿选址策略` | `必带原件与穿搭清单` | `乘车码与离线截图` | `防坑提醒与当地 12345 热线`。

## 三、技术实现与视觉质检工作流

### 1. 图片素材原则
- 优先使用高分辨率无水印实拍或与目标城市风貌高度吻合的视觉素材；同一份路书尽量覆盖景点、人文、街区与餐饮四大视角。
- 每张新图片入版前须用 `read_file` 目视抽检构图、色彩与内容真实性，禁止使用含错别字、水印或与当地真实风貌明显不符的图片。

### 2. HTML/CSS 到 PDF 编译规范
- **页面设置**：`@page { size: A4 portrait; margin: 10mm 11mm 10mm 11mm; }`，开启 `-webkit-print-color-adjust: exact; print-color-adjust: exact;` 确保背景色块与进度条完整打印。
- **字体建议**：正文 `"Microsoft YaHei", "PingFang SC", sans-serif`（`8.5–9pt`，行高 `1.4–1.45`），封面大标题可搭配 `"STZhongsong", "SimSun", serif`。
- **通用 HTML 启动模板**：可直接参考并复制修改 [lookbook-template.html](../examples/lookbook-template.html)。
- **一键导出与质检脚本（推荐）**：直接运行 [export_pdf.py](../scripts/export_pdf.py)（自动探测 Edge/Chrome、打印 A4 PDF 并用 PyMuPDF 导出每页 PNG 及字数统计）：
  ```bash
  python scripts/export_pdf.py --html examples/lookbook-template.html --out tmp/guide.pdf --preview-dir previews --dpi 160
  ```
- **导出引擎手动指令（Windows 实测稳定）**：使用 Microsoft Edge Headless 直接打印成 PDF：
  ```powershell
  & "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless --disable-gpu --no-pdf-header-footer --print-to-pdf-no-header --print-to-pdf="<OUT_PDF>" "file:///<HTML_PATH>"
  ```

### 3. 交付前 PyMuPDF 自动化校验与右侧预览同步
导出 PDF 后**必须运行校验脚本并逐页目检**：
1. 使用 `pymupdf` 读取输出 PDF，打印**总页数**、**非空白总字数**与**文件体积**，确认未因多出几行字挤出空余尾页；
2. 将每一页按 `160 dpi` 渲染为 `pdf_page_1.png` ... `pdf_page_N.png` 并调用 `read_file` 逐页检查：
   - 确认图例文字、SVG 标注、价格角标无碰撞或遮挡；
   - 确认深色图片遮罩上的浅色字清晰可读；
   - 确认每页底部留白合理，无跨页撕裂卡片。
3. 将原 PDF 路径与包含渲染图及可复制正文的右侧 `UserFacing: true` `.md` 预览 Artifact 一并链接交付。
